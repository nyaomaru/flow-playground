# flow-playground

A tiny Flow playground to test type definitions.
Perfect for checking behaviors of opaque, empty, mixed, refinement, etc.

I recommend installing the VSCode extension `“Flow Language Support”` for syntax highlighting.

`// ❌` shows an error case.
If you want to verify the behavior, simply uncomment that line.

## Get started 🚀

```sh
pnpm i
pnpm flow
```

## 📝 Tips

- Don’t forget `// @flow` at the top of test files.
- `.flow` / `.js.flow` files require proper settings in .flowconfig to be included.
- VSCode may show `TypeScript` errors — disable TS validation in this workspace if needed.

Enjoy flowing! 🌊🔥
